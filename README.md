# Random Number Generator

This is the first project of 2 mini-projects that I want to do before the mega project(AKA the teased project on my blog website).

This is a Random Number Generator that generates a random number based on you given max range. For example, if your max range is 10, it will generate a random number between 1 and 10 only.

The main reason I wanted to make this is for the random number effect where it a few numbers are shown just for a bit and then the final number is your random number selected. Also, background is generated by ChatGPT. Hope you enjoy it! :)
